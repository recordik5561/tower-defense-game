# Tower Defense: Путь Героя — Полная инструкция по развёртыванию

Пошаговая инструкция для запуска первой версии (без опыта программирования).

## Что тебе понадобится
- Telegram-аккаунт
- GitHub-аккаунт (бесплатный)
- Аккаунт на Render.com (бесплатный)
- 30–60 минут времени

---

## Шаг 1. Создай бота в Telegram

1. Открой Telegram и найди бота **@BotFather**.
2. Напиши ему команду: `/newbot`
3. BotFather спросит имя бота — напиши, например: `Защита Башен`
4. Затем username (должен заканчиваться на `bot`), например: `TowerDefenseHeroBot`
5. BotFather пришлёт **токен** — длинную строку вида `123456789:AAH...`.  
   **Скопируй и сохрани её в надёжном месте.** Это ключ к твоему боту.

---

## Шаг 2. Захости игру (фронтенд) на GitHub Pages

Игра состоит из файла `index.html` и папки `imagine_images` с картинками.

1. Зайди на [github.com](https://github.com) и зарегистрируйся (если ещё нет).
2. Нажми **New repository**.
3. Назови репозиторий, например: `tower-defense-game`
4. Сделай его **Public**.
5. Нажми **Create repository**.
6. Загрузи файлы:
   - Перетащи в репозиторий файл `index.html`
   - Перетащи папку `imagine_images` целиком
7. Зайди в **Settings** репозитория → слева **Pages**.
8. В разделе **Build and deployment**:
   - Source: **Deploy from a branch**
   - Branch: **main** → папка `/ (root)` → **Save**
9. Подожди 1–2 минуты. GitHub даст адрес вида:  
   `https://твой-username.github.io/tower-defense-game/`

Проверь, что по этой ссылке открывается игра.

---

## Шаг 3. Подключи игру к боту

1. Вернись в **@BotFather**.
2. Напиши `/mybots` → выбери своего бота.
3. Нажми **Bot Settings** → **Menu Button** → **Configure menu button**.
4. Введи URL игры (из шага 2).
5. Название кнопки: `Играть` (или любое).
6. Готово. Теперь в чате с ботом внизу появится кнопка «Играть».

Также можно сделать полноценное Mini App:
- В BotFather напиши `/newapp`
- Выбери бота
- Укажи название, описание и URL игры

---

## Шаг 4. Запусти бэкенд (рейтинг + Stars)

Без бэкенда игра работает, но рейтинг будет только локальный, а магазин Stars — нет.

1. Зайди на [render.com](https://render.com) и зарегистрируйся (можно через GitHub).
2. Нажми **New** → **Web Service**.
3. Подключи свой GitHub-репозиторий (или создай отдельный для бэкенда).
   - Если хочешь отдельно: создай новый репозиторий и загрузи туда папку `backend` (файлы `server.js` и `package.json`).
4. Настройки:
   - Name: любое (например `tower-defense-backend`)
   - Runtime: **Node**
   - Build Command: `npm install`
   - Start Command: `node server.js`
5. В разделе **Environment** добавь переменную:
   - Key: `BOT_TOKEN`
   - Value: токен из шага 1
6. Нажми **Create Web Service**.
7. Render даст URL вида: `https://tower-defense-backend.onrender.com`

### Подключи бэкенд к игре
1. Открой файл `index.html` на GitHub (или локально).
2. Найди строку:
   ```js
   let backendUrl = 'https://your-backend.example.com';
   ```
3. Замени на URL своего бэкенда с Render.
4. Сохрани и залей обновлённый `index.html` обратно в репозиторий.

### Настрой webhook для Stars
1. В **@BotFather** напиши `/setwebhook`
2. Выбери бота.
3. Укажи адрес: `https://твой-сервис.onrender.com/webhook`
4. BotFather подтвердит.

---

## Шаг 5. Проверь всё

1. Открой своего бота в Telegram.
2. Нажми кнопку «Играть».
3. Пройди один уровень в режиме «История» — прогресс должен сохраниться.
4. Сыграй в «Бесконечные волны» — рекорд должен появиться в рейтинге.
5. Попробуй купить что-то в магазине (Stars) — должно открыться окно оплаты.

---

## Шаг 6. Финальный запуск

- Добавь описание бота в BotFather (`/setdescription`)
- Добавь аватар бота (`/setuserpic`)
- Расскажи друзьям и в чатах про игру
- Следи за балансом Stars в настройках бота (Monetization)

---

## Важные замечания

- **Бесплатный Render** «засыпает» после 15 минут бездействия. Первый запуск после сна занимает 30–50 секунд.
- Прогресс привязан к Telegram-аккаунту (user.id). При смене устройства прогресс подтянется, если бэкенд работает.
- Для реальных выплат Stars нужен рабочий webhook и бэкенд.
- Если что-то сломалось — проверь консоль браузера (F12) или логи на Render.

Готово! Первая версия запущена.
